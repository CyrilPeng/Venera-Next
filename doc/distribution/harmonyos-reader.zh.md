# HarmonyOS 完整阅读器实验包

这是 `HarmonyOS` 分支复用现有 Flutter/Dart **完整应用工程**构建的实验 HAP，不是之前的空白包或核心诊断探针。漫画源、阅读器、收藏、历史、下载和 WebDAV 使用原工程，不另写一个简化阅读器。**完整工程编译不等于全部系统能力适配或真机验收**；正式支持平台和稳定 Release 不变。

按 #77 反馈者的意愿，本阶段直接提供应用日常试用，**不再要求重复四步验证、探针报告或私人附件**。遇到实际问题再在 #77 回复即可。

## 获取与安装

1. 从维护者在 #77 给出的成功 Actions 运行下载 `harmonyos-reader-experiment-运行号`，不要选择 `harmonyos-unsigned-lab-haps` 里的探针。Artifacts 需登录 GitHub，保留 14 天；过期时请向维护者索取新的构建，不下载未知重签名包。
2. 解压后应包含 `venera-next-1.18.2-harmony.1-arm64-unsigned.hap`、`full-app-manifest.json`、`SHA256SUMS` 及双语安装指南。核对原始 HAP 的摘要；小白签名会改变包体摘要，不能用原始摘要验证重签后的包。
3. 已有鸿蒙端小白调试助手的用户可沿用其现有环境，导入该 **未签名 HAP** 后由自己完成账号登录、设备授权、签名和安装。维护者不收集账号、设备标识、调试授权、证书或私钥；不附签名密钥、不绕过鸿蒙安全策略、不承诺自动续签。
4. 应用显示名为 `VeneraNext (HarmonyOS Lab)`，独立包名为 `com.github.cyrilpeng.veneranext.harmony`，版本 `1.18.2-harmony.1+1`。它与旧诊断探针、卓易通内的 Android 包使用不同沙箱，不是覆盖探针后自动出现原数据的升级包。

构建只声明 ARM64 `phone` / `tablet`，最低/目标 SDK 为 `26.0.0`。此前仅一位 MatePad / HarmonyOS 7.0 用户自愿反馈了核心探针通过；**这不能证明完整应用在该设备或其他系统版本已经通过**。其他设备若不能安装，不要求其反复授权或降低系统安全设置。

## 直接开始使用

- 可在漫画源页面按原应用方式添加和安装源，再使用搜索、收藏、章节阅读、下载和历史。内嵌网页使用固定版本的 CPF Flutter OHOS WebView 适配；源自身的登录、验证和兼容性仍可能有问题。
- 本地优先导入 CBZ / ZIP / EPUB 或选择图片文件；系统文件选择器返回的 URI 会由原生接口复制到应用沙箱，再交给现有导入流程，不把 URI 当作已授权的普通路径。
- 「设置 → App」保留 `data.venera` 备份导入/导出和 WebDAV 同步。先另存原数据备份和漫画文件，再按需迁移；配置导入不自动复制旧平台的外部漫画目录，也不保证恢复 Android SAF / Windows 路径。
- 导出的备份、图片和漫画通过系统保存选择器写入用户选择的文件，完成复制并关闭文件后才返回成功。请自行确认另存文件可见，再考虑清理旧副本；不建议把实验包当作唯一数据副本。
- 退出/后台时沿用现有阅读会话与异步收尾；下载仅在应用可运行的生命周期内执行，不保证绕过鸿蒙后台限制。
- 后续实验包通过 #77 提供；应用内检查更新会提示该渠道，不把主线 Release 的 APK 等安装包当作 HAP 更新。

## 明确的首包边界

- 未接入外部目录长期授权、自定义存储目录、系统分享、生物识别应用锁、Android 音量键/SAF/前台服务。目录操作会说明改用归档导入，分享请先保存到「文件」或复制文本，不假报成功。
- PDFium 没有 OHOS 构建，因此 **PDF 导入不支持**；现有 Dart PDF 导出保留。构建不会拿 Android/Linux PDFium 库凑包。PNG、ZIP、7Z 使用当前工程锁定源码的真实 OHOS 原生重编译库。
- 若导入配置含应用锁，实验包明确告知没有鸿蒙应用认证，由用户选择继续或退出，不自动伪装认证成功；可在设置中关闭导入的应用锁。
- 尚未验证 WebView 代理覆盖、平台图片编解码差异、完整应用网络/TLS/登录、大文件迁移、设备帧率/功耗、完整应用覆盖升级或签名续期。特别不要把 #91 的功耗收益算作本包已测得。
- UI、依赖解析、宿主回归、ARM64 ELF/FFI、包名/版本/API、原生库及资产校验只证明相应构建检查，不等于用户验收。不自动关闭 #77，也不把该 HAP 发布到主线稳定渠道。

实际报错时在 #77 描述使用的功能和错误即可，截图可自愿提供并遮盖私人信息；无需上传配置、Cookie、漫画源凭据、设备日志原件或签名材料。
