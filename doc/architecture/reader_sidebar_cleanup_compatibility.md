# Reader sidebar cleanup and original hosts

Implementation baseline: `c2cda65aedd5f5dd12cffd7513b4c0a81a7bb7e4`.

ReaderSidebarBinding still acquires an interaction pause immediately, presents after the frame, suppresses duplicate pending/open requests and keeps the nearest Navigator. It now registers a WindowSelectionTask with the original application/window before invoking pause acquisition. Reentrant shutdown therefore waits for release; closed or replaced original hosts cannot admit new presentation or old handle actions.

Failed route removal ends presentation waiting while preserving the exact original route, error and stack for cleanup. The binding keeps retiring operations until removal succeeds. An old handle, binding.close, repeated disposal or original-host shutdown can explicitly retry. Concurrent binding close calls join the same attempt. Completed routes and borrowed releases are not replayed. A failing borrowed release keeps the existing report-once contract; it is not converted into a retryable resource. Removing the reader does not transfer its failed cleanup to a replacement application registry.

WindowSelectionTask now registers complete closeAndWait with the existing window drain at close start. Previously, close-start cancellation could fail presentation removal, complete operation.settled, and reach the exit callback, which retried the failed presentation within the same window close. The first failure now reaches the window before exit tasks; the window remains open and a later close explicitly retries. No new task framework, window implementation or application registry was introduced. Public operation/file cleanup, original application registration and presentation retry rules outside that close-start join are unchanged.

SideBarRoute layout, widths, safe-area behavior, animations, barriers and iOS gesture handling are unchanged. The reader shell and chapter-comment callers are unchanged. Source, download, JS, storage and CLI protocols are unchanged. Existing tests cover never-built/built Navigator disposal, replacement, input invalidation, pauses, chapter/comment layout, light/dark, large text and reduced motion. Native gesture interruption, device lifecycle and assistive-technology acceptance remain wider platform work.
