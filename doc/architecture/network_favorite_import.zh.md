- 收集阶段只读：目录名/关联在开始时预检，提交事务内再次检查。新目录直到收集成功才创建；关闭/抓取失败不保留空目录或部分抓取记录。这明确修正旧实现取消/失败后仍逐条导入的行为。

- 旧到新分页先获取总页数，起始页至少为 1；按页数上限读取。普通分页总页数及游标类型校验，重复游标报错；同一批次漫画 ID 去重，提交仍由仓储按 id/type 幂等去重。
