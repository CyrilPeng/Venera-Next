作用域使用每个 guard 实例的 Zone 所有者和存活 token。write 是同步边界，不会等待自己持有的独占操作；在退出排空时允许已接纳的 import/exclusive 所有者收尾，拒绝新写入；绑定旧 Zone 的迟到回调在 token 失效后被拒绝。它不把保留期内的任意异步子任务自动变为长期所有者，调用方仍须等待自己的工作。

CBZ/PDF/EPUB 的生产注册在 runImport 中，目录恢复在 runExclusive 中；备份恢复的生产分支经 CBZ.import。备份测试注入的 importer/register 回调不代表真实文件转换；下载队列是另一种显式所有者，不据此声称所有写入都进入 import 计数。
