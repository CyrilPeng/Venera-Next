# Comic Source Capability Compatibility Matrix

Updated 2026-10-09 for R1.2. Tests use Windows Flutter test, actual QuickJS libraries, assets/init.js, synthetic sources and isolated temporary data. They do not access third-party sources or personal data. The related-domain run has 745 passes and no skips; toolchain, logs and input bindings are in the [batch report](completion_batches_2026_10_09.md). Historical results remain tied to their original inputs.

Source tests without a directory prefix are under test/features/comic_source/; Cookie/JS tests are under test/foundation/ and test/network/. Normalization tests validate data shapes but do not replace native JS execution. Environments without actual libraries must report unverified coverage instead of inheriting local passes.

R1 adds 37 tests: two for each of 14 read families, three account actions, five synchronous hooks and one unsupported synchronous Promise. All 31 parser error boundaries classify cancellation while retaining cause/stack; Cookie validation retains its bool/false-on-failure contract. Account actions do not receive read retries; explicit authentication-expiration re-login remains. Public callback names/arguments, source keys, persisted formats and assets/init.js are unchanged. P7.2 remains P until R4 application and final compatibility evidence is available.
