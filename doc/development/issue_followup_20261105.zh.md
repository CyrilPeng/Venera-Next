## 本轮执行范围

### 收藏返回与路径导航（#123）

独立于上述候选实施，列入 changelog 的「未发布」部分：

1. 子目录返回先退出搜索或多选，再进入真实父目录；弹窗先关闭。一级目录、「全部」和网络收藏沿用已有应用返回流程。
2. 工具栏路径中的父目录可点击跳转，窄屏提供上一级按钮，完整名称保留在提示和无障碍标签中。极窄标题适配按钮间距，大字体根据工具栏可用高度显示。
3. 跳转按真实目录 ID 和最新父子关系校验；名称中的 `/` 仅作文字。移动、重建和重命名不会让旧按钮误跳到同名目录。
4. 返回后的目录选择正常保存，重启后恢复。保存期间的返回不会被吞掉，也不会在保存完成后重复跨层返回。

相关回归 116 项、TV flavor 专项 49 项通过。覆盖嵌套导航、弹窗／搜索／多选优先级、保存竞争、目录移动及重命名、重启持久化；路径控件覆盖 5 种尺寸、明暗主题、大字体、触控及键盘操作。严格静态分析、架构、导入边界和依赖清单检查通过。
