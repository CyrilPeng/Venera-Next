# 自动选择阅读模式

在「设置 → 阅读器」中开启「根据漫画版式自动选择阅读模式」，再分别选择：

- **页漫阅读模式**：初始为翻页（从右到左）。
- **条漫阅读模式**：初始为连续（从上到下），也可选择支持跨章节阅读的瀑布流。
- **未识别时使用**：沿用原有默认模式。

此功能默认关闭，升级后不会改变已有阅读习惯。开启「设备专用设置」后，可以为当前设备设置不同偏好。

## 为一本漫画指定模式

阅读器设置顶部的「本书阅读模式」可直接选择具体模式，无需开启其他单本设置。这个选择只影响当前漫画，优先于自动识别。选择「跟随默认」即可恢复自动选择；自动选择关闭时，则跟随设备或全局默认模式。

旧版本已启用的单本阅读模式仍然有效。亮度、手势等其他单本设置不会阻止自动选择模式。

## 识别与切换时机

程序只检查图片尺寸，不使用漫画源声明、标签、语言或图片内容。在线图片复用现有下载器与缓存，本地图片直接读取编码尺寸，不为识别解码完整位图。

识别会跳过当前章节首图，检查后续最多 6 张图片。至少取得 4 张有效图片后，按「高度 ÷ 宽度」判断：

- 至少 80% 的样本比例达到 2.5，判为条漫。
- 至少 80% 的样本比例位于 0.5～2.0，且没有达到 2.5 的长图，判为页漫。
- 其他情况保持未识别。封面、双页图和异常页面的影响通过多张采样降低；阅读器拆分双页、缩放后的尺寸不参与识别。

这些比例是保守的启发式规则，不保证准确识别。切成短图的条漫可能被判为页漫；四格漫画、拼接页及混合版式也可能误判。可以直接指定本书阅读模式，或点击「根据当前章节重新识别」。

首次识别最多额外等待 700 毫秒，超过后先用默认模式打开，识别在后台继续。用户开始阅读后不会自动切换操作方式；识别成功且对应偏好不同，会显示「应用阅读偏好」，也可以稍后在阅读器设置中应用。切换保留当前章节和对应的源图片位置；滚动图内的精确像素偏移不跨模式保留。

可靠的识别结果按「漫画源 + 漫画 ID」保存，下次打开直接使用；修改页漫或条漫的通用偏好后，跟随默认的漫画会在下次打开时使用新偏好。未识别的作品可以在后续章节再次识别。在线作品下载后保持同一身份时，会复用结果。
