# 关键词屏蔽与命中原因

[English](keyword_blocking.en.md)

> 本文介绍 `main` 的待发布功能。当前稳定版 `v1.18.3+249` 仍使用原有关键词匹配，尚未提供匹配方式、试匹配和原因编辑入口。

## 1. 添加或修改规则

在「设置 → 探索 → 关键词屏蔽」添加规则，点击已有关键词可以编辑。评论使用同一页面中的「评论关键词屏蔽」，两份列表分别管理。

每条规则包含关键词、匹配方式和「不区分大小写」开关。新规则默认开启此开关；输入 1–3 个英文字母时，界面推荐「独立词」。可以手动改用其他方式，之后继续输入不会覆盖你的选择。

| 匹配方式 | 适合的内容 | 实际检查范围 |
|---|---|---|
| 包含文字 | 中文词组、较长的作者名或明确的文字片段 | 标题、副标题和描述中包含这段文字；标签须完全相等 |
| 独立词 | `BL` 等容易出现在长单词内的短缩写 | 标题、副标题和描述中的独立文字；标签须完全相等 |
| 标签完全匹配 | 只想屏蔽某个标签，不想按标题屏蔽 | 完整标签，或标签命名空间后的名称；无标签的漫画不会命中 |

评论规则提供「包含文字」和「独立词」，只检查评论正文。关键词始终按字面文字解释，例如 `a.b`、`[BL]` 和 `a+b` 都是原样文字，无需学习或输入正则表达式。

## 2. 短缩写怎样避免误伤

规则为 `bl`、开启「不区分大小写」时：

| 示例标题 | 包含文字 | 独立词 |
|---|---|---|
| `black and white` | 隐藏 | 显示 |
| `[BL] Short stories` | 隐藏 | 隐藏 |
| `artist.bl.part01.zip` | 隐藏 | 隐藏 |
| `BL_stories` | 隐藏 | 隐藏 |
| `BL漫画` | 隐藏 | 显示 |

空格、标点、点号和下划线可以分隔独立词；相邻的 Unicode 字母、数字和组合标记不会分隔。中文通常没有词间空格，「独立词」不进行中文分词。要屏蔽「校园恋爱故事」里的「校园」，请选择「包含文字」。

标签完全匹配不依赖标题。`bl` 可以匹配标签 `BL` 或 `genre:BL`，不会匹配 `black` 或 `BL stories`。为保留旧标签格式，多个冒号时只取第一个冒号后的第一段：`genre:BL:other` 可被 `bl` 命中，`genre:other:BL` 不会。

## 3. 保存前试匹配

在规则编辑窗口点击「试匹配」，输入示例标题、示例标签或示例评论。界面显示「会被这条规则隐藏」或「不会被这条规则隐藏」，并高亮实际命中的文字；预览与列表使用同一套匹配逻辑。

试匹配只检查当前规则和输入的示例，输入示例不会保存为关键词。编辑后点击「添加」或「保存」；若保存失败，可保留编辑内容并重试。其他窗口已经修改或删除该规则时，旧编辑窗口会提示重新打开，避免覆盖新设置。

## 4. 查看漫画为什么被隐藏

漫画列表出现「关键词屏蔽隐藏了 … 本漫画」时，点击提示查看原因。每项显示当前列表内的漫画文字、首条实际命中的关键词、命中字段、匹配方式和大小写设置，并高亮命中部分。隐藏的封面不会重新显示。

点击「编辑规则」可直接修改导致隐藏的规则。保存后原因列表会重新计算，漫画列表也会更新；若仍被隐藏，可能还有其他规则命中，可再次查看原因。提示只检查当前列表已加载的漫画，不代表整个漫画库的数量。

从漫画卡片的「屏蔽」入口快捷添加时，新选中的标签使用「标签完全匹配」，1–3 个英文字母使用「独立词」，其余文字使用「包含文字」，默认忽略大小写。已经存在的关键词保留原规则，不会被快捷添加覆盖；可在关键词设置中进一步调整。

## 5. 旧规则、备份与同步

升级不会自动改变旧规则：漫画关键词继续区分大小写并按文字包含匹配，标签继续完全匹配；评论关键词继续忽略大小写并按文字包含匹配。打开旧规则后原样保存也保留原行为。

如果旧词 `bl` 误伤了 `black`，请编辑该规则，选择「独立词」，按需要开启「不区分大小写」，用 `black` 和 `[BL]` 试匹配后保存。

完整应用数据备份会保留词列表及匹配方式。应用数据同步中，排除一份关键词列表也会排除其匹配方式；漫画和评论两份列表分别生效。导入只含旧词列表的旧备份时，对应列表恢复旧匹配行为。

旧版应用无法使用新匹配方式，会按其原有包含匹配运行。共享数据的设备应统一升级到支持本功能的版本，回退前保留独立的完整备份，避免旧版同步覆盖新规则。
