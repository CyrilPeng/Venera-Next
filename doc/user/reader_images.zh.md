# 阅读器保存图片

English: [Saving reader images](reader_images.en.md)

Windows、Linux 和 Android 可在「设置 → 阅读器 → 图片保存目录」选择固定目录。选定后，底栏保存和右键「保存图片」直接写入这个目录，保存成功后显示位置。尚未选定目录时，每次通过系统保存窗口选择位置。

长按底栏保存按钮，或在右键菜单选择「图片另存为」，可以只为当前图片选择其他位置。设置中的「每次询问」可以取消固定目录。

目录只保存在本机，不随 WebDAV 或应用数据备份传到其他设备。Android 使用系统授予的持久目录权限，不要求把文档目录换成普通文件路径。目录被移除、权限撤销或存储 Provider 不再支持写入时，会提示重新选择，并继续保存已经选中的原图；取消不会创建图片。

保存保留原图内容与实际扩展名，文件名包含标题、章节和原图页码，例如 `漫画_EP2_P13.jpg`。非法文件名字符会替换，过长标题会缩短，章节、页码和扩展名保留。同名文件自动增加序号，例如 `漫画_EP2_P13 (1).jpg`，已有文件保留。

写入失败会明确报告失败；可确认归属的本次新建文件会清理。应用关闭会等待已经开始的写入及系统文档收尾。

其他平台通过各自的系统保存入口保存图片。
