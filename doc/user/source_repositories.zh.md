# 漫画源与源仓库

English: [Source repositories](source_repositories.en.md)

“漫画源”页面分为 **已安装** 和 **源仓库**。漫画源是访问漫画服务的脚本；源仓库是可供浏览和安装这些脚本的目录。可以保存多个仓库。

## 添加与安装

1. 打开“漫画源 → 源仓库 → 添加仓库”。
2. 填写容易辨认的名称和完整的源列表地址（通常是 `index.json`）。
3. 点击“保存”。应用会先检查地址和目录格式；失败时保留输入并显示原因，取消不会保存。
4. 在仓库中点击“浏览漫画源”，搜索并安装需要的源。安装完成后可在“已安装”中查看。

已有单个 `.js` 脚本链接或文件时，使用“已安装”中的“通过链接安装”或“从文件导入”。不要把目录地址填进脚本链接输入框。

## 连续安装与任务进度

点击一个源的“安装漫画源”后，可以马上安装下一个，也可以继续搜索、刷新或切换仓库。进度显示在对应源下方，不再弹出阻塞操作的进度框。

- 应用最多同时下载 3 个源，超出的任务显示“等待下载”；下载后依次完成安装。有文件总大小时显示真实下载百分比。
- 页面顶部的“安装任务”可以查看本次使用期间的所有任务、来源和完整失败原因，并清理已结束的记录。
- 等待下载、下载中或等待安装的任务可以取消；安装提交中的任务会先完成。失败后可以单独重试，不影响其他任务。
- 关闭仓库目录、离开漫画源页后，任务继续运行；返回时仍能查看。退出应用会结束未完成的任务，重启后需要重新发起。
- 同一个源正在安装时，其他仓库中的对应条目也会显示已有任务，不会重复安装。若来源仓库已被删除或修改地址，请重新打开仓库后发起安装。
- 通过链接安装和文件导入同样进入任务列表。完成后，源及其来源、搜索和发现入口自动保存。

## 来源与更新

每个已安装源下方显示来源。点击来源或操作菜单中的“管理来源”，可以选择一个已保存仓库，再从匹配条目中确认关联。

- 从仓库安装的源自动关联该仓库。检查版本和下载更新都使用关联仓库中的对应条目。
- 同一个源可以出现在多个仓库中，但不会重复安装。选择“使用此仓库”会改变之后的更新来源；当前脚本及设置保留到下次更新。
- 旧源没有可靠的来源记录，会显示“未关联仓库”。通过链接或文件安装的源显示对应安装方式。
- 未关联有效仓库的源不参与目录版本检查，仍可通过源脚本声明的地址手动更新。
- 检查结果会说明已检查、未检查的数量及加载失败的仓库；某个仓库失败不影响其他仓库。
- 仓库中不再包含该源，或同一个标识对应多个无法确定的版本分支时，需要重新选择来源。

已安装列表默认收起各源的设置，点击展开按钮可以管理原有设置和账号。

## 编辑、移除与旧数据

仓库菜单可以编辑名称、地址或移除仓库。修改仓库地址会影响关联源今后的更新位置。“刷新列表”只重新加载已保存地址的目录。

移除仓库不会卸载漫画源，也不会删除源设置和阅读数据；这些源会显示“仓库已移除”，可以关联到其他仓库。卸载漫画源是独立操作。

升级时，原先保存的单个源列表地址会迁移成一个仓库，已安装源保持原样。仓库列表和安装来源保存在应用数据目录的 `appdata.json` 中，并沿用现有备份和同步机制。
