# 两级本地收藏目录

> 主线功能，尚未发布，对应 #123。以下说明适用于包含此功能的构建；已发布的 v1.18.1 和 v1.18.2-rc.6 不包含此功能。

本地收藏最多支持两级。一级目录和二级目录都可以直接收藏漫画，网络收藏仍由漫画源管理，不因此变成两级目录。首版继续要求所有本地目录名称全局唯一，即使父目录不同也不能重名。

## 升级与旧数据导入

- 升级前，在「设置 → 应用 → 数据」导出并另存完整应用数据备份，保留原漫画文件。
- 首次升级收藏数据库时，应用先在数据目录的 `.favorite_hierarchy_backup_*` 子目录保存独立的旧库快照；快照失败或迁移失败会停止初始化，不清空收藏库。
- 原收藏夹全部保留为一级目录，保留名称、有效顺序、漫画、网络收藏关联和追更记录，不自动分类或搬动漫画。
- 名称中的 `/` 等字符只是名称的一部分，不会被拆成父子目录。
- 恢复旧版完整应用数据备份时同样将原收藏夹作为一级目录；导入旧版单夹 JSON 时也始终新建一级目录，不受创建窗口当前选择的父目录影响。同名导入沿用自动追加编号的规则，不覆盖原目录。
- 新格式层级损坏或版本不受支持时，应用拒绝导入，不会通过清库或压平目录来绕过错误。

## 浏览与收藏

收藏侧栏中，点击目录名称进入该目录，点击左侧箭头独立展开或折叠子目录。搜索框可以按名称或「父目录 / 子目录」路径查找目录；清除搜索不会改变已保存的层级。

一级目录页同时提供子目录入口，但下方漫画列表和目录计数只包含**直接收藏在本目录**的漫画，不汇总子目录。漫画搜索、阅读状态筛选和屏蔽词继续作用于当前漫画列表。「全部」视图包含所有层级的收藏，按漫画身份去重；同一本漫画可同时存在于多个目录。

漫画详情收藏、批量添加／转移、快速收藏设置和追更目录选择共用可搜索的目录选择器。选择器显示完整路径，实际收藏和设置仍指向原目录；父目录和子目录可以分别选择。快速收藏也可以设为「无」。

TV 版可使用方向键移动焦点、确定键选择目录或展开箭头，返回键关闭选择器并回到原控件。在目录搜索框中，上下键移出输入焦点，左右键保留光标编辑；排序提供上移／下移按钮，无需拖拽。这些操作不改变 TV 独立数据与低内存策略，实际设备输入法仍可能需要配套输入设备。

## 创建、移动与排序

- 「新建收藏夹」可选择「一级目录」，也可以选择一个一级目录作为父目录。在一级目录菜单中可直接「新建子目录」。二级目录不能再创建下一层。
- 「移动目录」只修改父子关系，不搬动漫画、不改变目录名称；快速收藏、稍后再读、追更及网络收藏关联仍指向原目录。
- 没有子目录的一级目录可以移入另一个一级目录；二级目录可以换到另一个一级目录下，或移回一级。带子目录的一级目录不能再移入其他目录，避免产生第三级。
- 排序窗口默认调整一级目录顺序；有二级目录时，可切换父目录调整其子目录顺序。支持拖拽，也提供上移／下移按钮。关闭排序窗口后保存，同级排序不会改变层级。
- 一级目录仍有子目录时禁止直接删除。请先移动或删除子目录，再删除父目录；删除目录只删除其中的收藏记录，不删除漫画原文件，也不删除同一本漫画在其他目录中的收藏。

## 备份与同步

| 方式 | 保留范围 |
|---|---|
| 完整应用数据备份／恢复 | 保留目录标识、两级关系、同级顺序、直接收藏和关联信息；设置仍遵循原有导入规则 |
| WebDAV 应用数据同步 | 使用完整收藏数据库快照，保留层级；设置排除项仍生效，不进行多端目录冲突合并 |
| 单夹 JSON 导出／导入 | 沿用旧格式，仅导出本目录直接收藏；导入为新的一级目录，不包含父子关系 |

一级目录含有子目录时，导出菜单会明确显示「仅导出本夹漫画（不含子目录）」。需要完整目录树时，请使用完整应用数据备份，不要把单夹 JSON 当作整个目录树的备份。完整应用数据不包含本地漫画图片，仍需另行保留漫画文件。

**不要让新旧版本交替读写同一份收藏库或 WebDAV 数据。** 旧版不了解新增层级元数据，修改排序等操作可能破坏关系。参与同步的设备应使用支持此功能的版本。回退前另存新版数据，并使用升级前的备份恢复；不保证旧版能正确处理新版已修改的数据。

更多同步设置见[应用数据同步](data_sync.zh.md)。
