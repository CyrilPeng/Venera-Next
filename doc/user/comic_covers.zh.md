# 漫画封面更新

[English](comic_covers.en.md)

网络漫画的封面会随源站变动。应用先显示已有封面，只对正在显示的作品进行后台校验，校验成功后更新图片。封面校验默认间隔为 24 小时，并发最多两项；滚动离开、页面隐藏或应用进入后台后停止该封面的展示用更新。失败时保留旧图，等待五分钟后再按需尝试。

打开详情、刷新漫画信息或检查更新时，源返回的新封面地址会同步到该漫画已有的收藏和历史。收藏顺序、收藏时间、标签和阅读进度不会因为封面同步而改变。

在漫画详情右上角的菜单中选择 **刷新封面**，可以立即重新获取封面地址和图片。刷新时菜单按钮显示进度，结束后显示成功或失败提示。失败后仍可查看原封面。

源站支持 HTTP `ETag` 或 `Last-Modified` 时，自动校验会询问图片是否变化；没有变化时继续使用已有图片。封面地址未变但图片内容已变，也能在校验或主动刷新后更新。源的请求头、签名地址与图片处理规则继续生效。

本地导入漫画和已下载漫画的本地封面保持原样，不会自动访问网络或替换离线文件。网络漫画的收藏和历史可以继续更新其网络封面。
